## Modelo de recorte

La aplicación descarga `BritishWerewolf/U-2-Netp` desde Hugging Face al usar por primera vez el recorte automático. El model card indica licencia Apache 2.0 y atribuye el modelo a `rembg` y al proyecto original [U-2-Net](https://github.com/xuebinqin/U-2-Net). El modelo no se almacena en este repositorio.
